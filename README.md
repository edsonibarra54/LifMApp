# LifMApp
LifMApp is a life management application for personal use with several tools that could be useful in the day by day or on specific ocations.

## Branch Types

| Prefix | Purpose | Example |
|---|---|---|
| `main` | Main branch (protected) | `main` |
| `Release/?.?.?` | Release branch (versioned) | `Release/2.1.5` |
| `Feature/FeatureName` | Feature branch | `Feature/PaysheetOrganizer` |
| `UserStory/USName` | User Story branch | `UserStory/AddNewPaysheet` |
| `Task/USName` | Task branch | `Task/CreateModalForLogout` |
| `Bugfix/BugName` | Bugfix branch | `Bugfix/GraphsNotLoading` |
